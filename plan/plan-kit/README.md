# 方案板草稿格式速查

你只写一份短 Markdown 草稿,`plan.py` 把它拼成网页,并在生成时检查;不合格不出页面。
完整例子:`examples/board-proposal-redesign.md`(合格)· `examples/bad-wall-of-text.md`(被拦下)。

```bash
python3 plan.py lint   草稿.md [--strict]      # 只检查
python3 plan.py render 草稿.md -o 输出.html     # 先检查,有 error 不出页面(退出码 1)
python3 plan.py patch  输出.html --section "节标题或序号" < 新的一节.md
python3 plan.py selftest
```

- `render` 的草稿写 `-` 表示从标准输入读(此时必须给 `-o`)。
- `patch` 只换那一节(连同目录、顶部「有几件要你定」、内嵌的草稿原文),其余字节不动,原地写。
  新的一节必须以 `## 标题` 开头且只有这一个 `##`;换完整页检查不过 ⇒ 报错、文件不动。

## 骨架

```markdown
---
title: 状态板与方案板 · 优化方案
line: 状态板线
date: 2026-10-06
status: 提议中
---

**结论:两处要动。** ① 状态板改成直接点选。② 方案板由工具生成。

## 方案板改成由工具生成页面

正文、图、要他定的题……

## 不改什么

配色和三块结构都不动。
```

- frontmatter 四项必填;`date` 写 `YYYY-MM-DD`;`status` 只能是 `提议中` 或 `已定`。
- frontmatter 后**第一段 = 结论**(必填,≤120 字)。
- `## 标题` = 一节,自动编号。标题是一句完整的结论(≥6 个字,不以冒号结尾)。`## 不改什么` 例外放行,鼓励写。
- 节内可用 `###` 小标题。草稿里的原始 HTML 一律被转义,不会生效。

## 零件(围栏块)

### decision — 要他定的题

````markdown
```decision
方案板归谁管？
cost: 现在没人管。不定的话这套工具没人能动。
- *状态板线接管 | 结构、工具、检查归我。
- 仍归设计系统线 | 我把这份方案交给它做。
```
````

- 第一行是问题;`cost:` 写不定会卡住什么;选项 `- 标题 | 说明`,至少 2 个。
- 恰好一个选项以 `*` 开头(`- *标题 | 说明`)= 建议,页面上默认选中。
- 「其他(我自己写)」选项和多行补充框由工具自动加,**不要自己写**。
- 题的 id 默认由问题文字算出(问题一改,旧答案就不再对上)。两道题问法相同、或想让 id 稳定,加一行 `id: owner-plan`。
- 题不能放进 fold。

### flow — 流程图

````markdown
```flow
✕ 现在
AI 手写整页网页 -> 没人查 -> 你在聊天里打字回答
✓ 改成
AI 只写草稿 -> !工具拼页面 | 图和选项是零件: 当场检查
工具拼页面 -> 你点选项
cap: 图下面的一句说明(可不写)
```
````

- 一行一条 `A -> B: 标注`;也可以连写 `A -> B -> C`(标注只落在最后一段)。标注用**英文冒号**,尽量 ≤8 个字。
- `!A` = 强调这个节点;`A | 小字` = 节点第二行小字。同名节点是同一个方框。
- `✕ 标题` / `✓ 标题` / `@ 标题` 另起一条泳道(红 / 绿 / 中性),不写就是一条中性的。
- 方框按出现顺序从左到右排,一行放不下自动折到下一行。

### compare — 前后对比

````markdown
```compare
✕ 现在的一页
> 一大段原样的长文字(以 > 开头:渲染成淡色、截断的「文字墙」)
cap: 32 步纯文字,没有图。
✓ 改后的一页
**1 上新分四段,只有第三段要人看。**
`登记` → `写文案` → `出图` → `上架`
cap: 标题是结论,图在前。
```
````

两栏都要有;每行一条短文字(可用行内 Markdown);`cap:` 是这一栏的图注。

### bars — 条形图

````markdown
```bars
你答了,板还挂着 | 13 | 13 | 13　上周 8
在做的活看不出到哪了 | 4 | 13 | 4　上周 8 | ok
cap: 图下面的一句说明(可不写)
```
````

`标签 | 数值 | 满格值 | 右侧文字 | ok`。数值、满格值必须是数字;满格值不写 = 取本图最大值;
右侧文字不写 = 显示数值;第 5 格写 `ok` = 绿色条(默认红色)。

### steps — 分步卡片

````markdown
```steps
第 1 步 · 2 天 | 方案板工具第一版 | 拿一页真方案重做给你看。
第 2 步 · 3 天 | 在板上直接答 | 点完当场记下。
```
````

### fold — 收起的细节

`````markdown
````fold 细节:五类检查各查什么
这里是普通 Markdown,默认收起。里面还要放别的围栏块时,外层用 4 个反引号。
```bars
甲 | 1 | 2
```
````
`````

标题写在围栏同一行。fold 里的字和图不算「露在外面」。

### draft — 要他审的原稿(图文审稿用)

`````markdown
````draft 小红书正文
第一段正文……(原样贴,不用压字数)

![封面](img/01.png)
![第二张](img/02.png)
````
`````

- 要他审的稿本身(社媒正文、串推、配图、长文)放这里:单列排、字号大一点;**同一段里的几张图排成网格**,在 8777 上**点任一张图全屏看**(←/→ 翻页)。
- 稿里的字**不算**页面字数上限(稿多长是稿的事);标题算。稿里有图 = 这一节有图。
- 题(decision)不能放进 draft。几份稿就写几个 draft 块,⛔ 别手写左右两栏把两段长文并排。

### 普通 Markdown

段落、`-` / `1.` 列表(可缩进嵌套)、表格、`>` 引用、`**粗**`、`*斜*`、`` `代码` ``、
`[链接](地址)`(新标签页打开)、`![说明](相对路径或 http 地址)`、其他语言的代码块。
图片的相对路径是相对**输出的 html** 算的。

## 检查规则

每条报错都带草稿行号、哪里不对、一个写对的例子。

| 级别 | 代码 | 规则 |
|---|---|---|
| error | `meta` | frontmatter 缺项、date 格式不对、status 不是两个值之一 |
| error | `lead-missing` / `lead-long` | 没有结论段 / 结论超过 120 字 |
| error | `head-short` / `head-colon` | 节标题不足 6 个字 / 以冒号结尾 |
| error | `sec-wall` | 一节露在外面的文字超过 300 字,而这一节没有任何图 |
| error | `page-long` | 全页露在外面的文字超过 2500 字 |
| error | `page-nofig` | 超过 800 字的页面一张图都没有 |
| error | `dec-opts` / `dec-sug` / `dec-cost` | 题少于 2 个选项 / 没有或有多个建议 / 没写 `cost:` |
| error | `dec-dup` / `dec-fold` | 两道题 id 相同 / 题写在 fold 里 |
| error | `rel-date` | 出现 今天 / 今晚 / 明天 / 昨天 / 明早 / 今早 |
| error | `syntax` | 围栏没关、零件里的行写得不对 |
| error | `cell-long` | 表格一格超过 60 个字(fold 里的表格不查) |
| warn | `sent-long` | 一句话超过 45 个字 |
| warn | `para-long` | 一段超过 6 句 |

warn 不拦;`--strict` 时当 error。口径:

- **字数** = 去掉空白后的字符数(汉字、标点、字母、数字各算 1)。
- **露在外面的文字** = 结论、节标题、段落、列表、引用、小标题、fold 的标题、图注。
  fold 里面的、表格格子、题、图里的字**不算**进 300 / 800 / 2500。
- **图** = flow / compare / bars / steps / 表格 / 图片,而且要露在外面(fold 里的不算)。
- `rel-date` 查所有露在外面的字,**包括**表格、题、图里的字;只有 fold 里和反引号里的不查。
  要引用界面上的字就写成 `` `今天新增` ``。
- `sent-long` 按 。！？；和换行断句;查结论、正文、图注、题;代码和链接地址不算。

## 页面自带的东西(不用写)

- 单栏,最大宽 820px,浅色;目录是顶部一条默认收起的条,列各节和每道题(没答红、答了绿)。
- 右下角「还有 N 个要定 ↓」和「生成回复」。回复只复制到剪贴板,不自动发送。
- 他一点选项或写补充,页面 `POST /_answer` 记到本机服务;打开时 `GET /_answers?page=<文件名>` 读回,
  题头显示「你 MM-DD 答了:…」。接口不存在时页面照常工作(此时只在浏览器本地留一份)。
- 页面里内嵌了草稿原文(`<script type="text/plain" id="plan-source">`),`patch` 靠它。

## 改样式

`plan.css` 和 `plan.js` 由 `plan.py` 读进来内联进每一页;不要引任何外部网址。
改了它们之后,旧页面要重新 `render` 才会换上新样式(`patch` 不动样式)。
